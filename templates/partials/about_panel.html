ICMP monitoring

About

This system checks PC reachability, packet loss, and round-trip latency using ping.

System Architecture

PingWatch is an enhanced ICMP monitoring and diagnostic suite. It combines 5-probe burst latency measurements, dual gateway/external reference comparison, and a 3-model machine learning pipeline (Isolation Forest, GRU, XGBoost) for automated anomaly detection, reachability forecasting, and actionable network troubleshooting recommendations.

  • Port: Configured for local dashboard and separated navigation routes.
  • Persistence: Crash-safe SQLite storage with multi-building database switching.
  • ML Pipeline: 12 temporal feature extraction pipeline with human-in-the-loop validation.
